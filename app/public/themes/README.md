# Темы оформления

Тема — это папка с описанием и стилями. Встроенные темы лежат здесь, в `public/themes/`, а свои кладите в `custom/public/themes/`. Тема с тем же именем папки заменяет встроенную.

```text
custom/public/themes/
└── my-theme/            ← id темы: латиница в нижнем регистре, цифры, дефис
    ├── theme.json       ← описание (обязательно)
    └── theme.css        ← стили (необязательно)
```

После добавления или изменения темы перезапустите приложение (`docker compose restart app`). Тема появится в **Администрирование → Оформление** и в личных настройках пользователей (**Настройки → Оформление**).

## theme.json

```json
{
  "name": "Моя тема",
  "description": "Короткое описание для карточки выбора",
  "author": "Имя автора",
  "preview": {
    "bg": "#f5f5f7",
    "header": "#ffffff",
    "headerText": "#1d1d1f",
    "sidebar": "#ebebf0",
    "card": "#ffffff",
    "text": "#1d1d1f",
    "accent": "#0071e3",
    "radius": 10
  }
}
```

Блок `preview` задаёт только цвета мини-превью на карточке выбора: `#hex`, `rgb()` или `rgba()`. На сам сайт он не влияет.

## theme.css

Файл подключается после базовых стилей [`public/css/app.css`](../css/app.css) и перед цветами из админки:

```text
app.css  →  theme.css темы  →  /theme.css (цвета из админки)  →  custom.css
```

Чаще всего достаточно переопределить CSS-переменные. Полный список — в начале `app.css`, основные:

| Переменная | Что задаёт |
| --- | --- |
| `--primary` | основной цвет: кнопки, ссылки, выделение |
| `--bg`, `--surface`, `--bg-soft` | фон страницы, карточек, лёгкие подложки |
| `--text`, `--text-muted` | основной и второстепенный текст |
| `--border`, `--border-strong` | рамки |
| `--header-bg`, `--header-text` | шапка |
| `--font-body`, `--radius` | шрифт и скругление углов |
| `--shadow`, `--shadow-lg` | тени карточек и выпадающих меню |
| `--topbar-height` | высота шапки |

**Тёмный режим** переключается кнопкой ◐ и включается атрибутом `data-mode="dark"` на `<html>`. Задайте для него свои значения:

```css
:root {
  --primary: #0071e3;
  --bg: #f5f5f7;
}
:root[data-mode="dark"] {
  --primary: #0a84ff;
  --bg: #000000;
}
```

Если одних переменных мало, переопределяйте классы компонентов: `.topbar`, `.card`, `.btn`, `.sidebar`, `.space-content`, `.markdown-body` и другие. Хороший пример — [`icloud/theme.css`](icloud/theme.css).

Советы:

- производные цвета лучше считать от `--primary` через `color-mix(...)`: тогда фирменный цвет, заданный в админке, правильно ляжет и на вашу тему;
- `https://ваш-сайт/?theme=my-theme` показывает тему на одной странице без сохранения, это удобно при разработке;
- внешние шрифты и картинки по умолчанию запрещены политикой безопасности (CSP): кладите файлы рядом с `theme.css` и подключайте относительными путями.
