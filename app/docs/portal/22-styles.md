Оформление построено на CSS-переменных: базовый файл задаёт значения по умолчанию, тема оформления их переопределяет, а цвета из админки ложатся поверх.

[[toc]]

## Порядок подключения стилей

```text
/css/app.css             базовые стили, они же тема «Классическая»
      ↓ переопределяет
/themes/<id>/theme.css   стили выбранной темы (у «Классической» файла нет)
      ↓ переопределяет
/theme.css               заполненные в админке цвета, шрифт, скругление + «Собственный CSS»
      ↓ переопределяет
/custom.css              файл администратора из custom/public (если есть)
```

## public/css/app.css

Файл разбит на пронумерованные разделы (оглавление — в его начале): переменные и тёмный режим, базовые стили, шапка, кнопки, формы, уведомления, карточки, макет пространства, дерево, страница, типографика статьи, макросы и подсветка кода, комментарии и таблицы, редактор, история и diff, поиск и админка, настройки и профиль, адаптивность, печать.

### Основные переменные

| Переменная | Что задаёт |
| --- | --- |
| `--primary` | основной цвет: кнопки, выделение, активные элементы |
| `--primary-hover`, `--primary-soft`, `--link` | **производные** от `--primary` через `color-mix` |
| `--bg`, `--bg-soft`, `--bg-hover`, `--surface` | фон страницы, подложки, наведение, карточки |
| `--text`, `--text-muted` | текст |
| `--border`, `--border-strong` | рамки |
| `--header-bg`, `--header-text`, `--topbar-height` | шапка |
| `--font-body`, `--font-mono`, `--content-font-size` | шрифты |
| `--radius`, `--shadow`, `--shadow-lg` | скругления и тени |
| `--content-max`, `--sidebar-width` | ширина текста и боковой панели |
| `--switch-on` | цвет включённого переключателя |

`color-mix(in srgb, var(--primary) 12%, transparent)` вычисляет оттенки прямо в браузере, поэтому при смене одного `--primary` пересчитываются все зависимые цвета.

## Светлый и тёмный режим

- Атрибут `data-mode="light|dark"` на `<html>` ставит `public/js/theme-init.js` **до отрисовки** (скрипт синхронный), поэтому страница не «моргает» белым.
- Порядок выбора: выбор пользователя в `localStorage['color-mode']` (`light`, `dark`, `auto`) → режим по умолчанию из админки (`data-default-mode`) → при `auto` системная настройка ОС (`prefers-color-scheme`).
- В CSS тёмный режим — те же переменные с другими значениями в блоке `:root[data-mode="dark"] { … }`.

:::note «Режим» и «тема» — разные вещи
**Режим** (светлый/тёмный) выбирается в браузере. **Тема** (Классическая, iCloud…) выбирается на сервере и подключается отдельным CSS-файлом. У каждой темы есть оба режима.
:::

## Темы оформления

### Реестр тем (src/services/themes.js)

При старте `loadThemes()` сканирует две папки:

| Папка | Что там |
| --- | --- |
| `public/themes/<id>/` | встроенные: `classic`, `icloud` |
| `custom/public/themes/<id>/` | темы администратора; тема с тем же `id` **заменяет** встроенную |

В каждой папке лежат `theme.json` (название, описание, автор, цвета превью) и необязательный `theme.css`. Обе папки раздаются как статика, поэтому стили доступны по адресу `/themes/<id>/theme.css`.

Реестр защищается от некорректных данных:

- `id` — только латиница в нижнем регистре, цифры и дефис;
- цвета превью пропускаются только как `#hex`, `rgb()` или `rgba()`: они вставляются в атрибут `style` карточки, и через них нельзя внедрить CSS;
- метка BOM в начале `theme.json` отбрасывается (её добавляют Блокнот Windows и PowerShell);
- битый JSON не роняет сервер: тема пропускается с предупреждением;
- тема «Классическая» есть всегда, даже если её папку удалили.

### Какая тема показывается

Порядок описан на странице [Middleware](page:Middleware) (`resolveTheme`): предпросмотр `?theme=<id>` → тема пользователя из профиля → тема сайта → «Классическая». `id` активной темы выводится в `<html data-ui-theme="…">`, поэтому в CSS можно адресовать конкретную тему: `:root[data-ui-theme="icloud"] .topbar { … }`.

### Тема «iCloud»: использованные приёмы

| Приём | Как сделано |
| --- | --- |
| «Матовое стекло» | `backdrop-filter: saturate(180%) blur(20px)` на шапке, боковых панелях, меню, панели редактора |
| Фон с цветными пятнами | несколько `radial-gradient` + `background-attachment: fixed` |
| Кнопки-таблетки | `border-radius: 980px` |
| Системная заливка Apple | `--fill: rgba(118,118,128,.12)` для вторичных кнопок, поиска, сегментированных переключателей |
| Статья на «листе» | `.space-content` — белая карточка со скруглением 22px поверх фона |
| Выбранный пункт меню как в macOS | залит `--primary`, текст белый |
| Переключатели iOS | `--switch-on: #34c759` |
| Тёмный режим | палитра тёмного macOS (`#000`, `#1c1c1e`, `#0a84ff`) |

:::tip Специфичность в темах
Если правило темы должно перебить более общее правило, объявленное ниже в том же файле, повышайте специфичность (`.topbar .btn-create`, а не `.btn-create`). Иначе, например, общее `.btn` перекрасит кнопку «+ Создать».
:::
