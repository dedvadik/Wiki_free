Полный список адресов портала. Права: **все** — доступно и гостю (если не включена «закрытая вики»), **вход** — любой вошедший пользователь, **редактор** — роль editor и выше, **админ** — только admin. Для пространств и статей дополнительно действуют права на само пространство: **чтение**, **правка**, **управление** (см. [Права доступа к пространствам](page:Права доступа к пространствам)).

## Порядок подключения

Роутеры подключаются в `src/app.js`. Публичные (`publicApiRouter`, `authRouter`) стоят **до** `siteAccess`, остальные — после. Поэтому в закрытой вики вход и стили доступны гостю, а всё остальное нет.

:::warning Порядок внутри роутера важен
Express проверяет маршруты в порядке объявления. Маршрут просмотра страницы `/pages/:id{/:slug}` объявлен **последним**, иначе `/pages/5/history` был бы принят за страницу со слагом `history`. По той же причине `POST /admin/settings/reset` объявлен раньше `POST /admin/settings/:section`.
:::

## Служебные — routes/api.js

| Метод | Адрес | Права | Назначение |
| --- | --- | --- | --- |
| GET | `/healthz` | все | проверка работоспособности (Docker HEALTHCHECK): `{"status":"ok"}`, если БД отвечает |

## Пространства — routes/spaces.js

| Метод | Адрес | Права | Назначение |
| --- | --- | --- | --- |
| GET | `/spaces` | все | каталог пространств, которые пользователь может читать |
| GET, POST | `/spaces/new`, `/spaces` | редактор | создание; создатель становится владельцем |
| GET | `/spaces/:key` | чтение | главная пространства (регистр ключа не важен) |
| GET, POST | `/spaces/:key/edit`, `/spaces/:key` | управление | название, иконка, цвет, описание |
| POST | `/spaces/:key/delete` | админ | удаление с подтверждением вводом ключа |
| GET, POST | `/spaces/:key/permissions` | управление | кто читает, кто правит, владелец |
| POST | `/spaces/:key/members` | управление | добавить участника или сменить его уровень доступа |
| POST | `/spaces/:key/members/:userId/delete` | управление | убрать участника |

## Администрирование — routes/admin.js

Все адреса `/admin…` закрыты `adminRouter.use('/admin', requireRole('admin'))`.

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | `/admin` | обзор: статистика, разделы, новые пользователи, система |
| GET | `/admin/settings` | → `/admin/settings/general` |
| GET, POST | `/admin/settings/:section` | раздел настроек `general` / `access` / `appearance`; сохраняет только свои поля |
| POST | `/admin/settings/reset` | сброс группы настроек к умолчаниям |
| GET, POST | `/admin/ldap` | настройки LDAP |
| POST | `/admin/ldap/test` | пошаговая проверка подключения к LDAP |
| GET, POST | `/admin/users` | список и создание пользователей |
| GET, POST | `/admin/users/:id` | роль, блокировка, сброс пароля |
| POST | `/admin/users/:id/delete` | удаление (контент остаётся) |
