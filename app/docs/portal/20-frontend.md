Интерфейс собирается на сервере: каждый адрес отдаёт готовый HTML из EJS-шаблона. Браузер получает три вида файлов: HTML, CSS (базовый, тема, настройки) и немного JavaScript для удобства.

[[toc]]

## Из чего состоит страница

```text
<html data-default-mode="light" data-ui-theme="icloud">
  <head>
    theme-init.js        ← до отрисовки ставит светлый/тёмный режим
    /css/app.css         ← базовые стили (= тема «Классическая»)
    /themes/<id>/theme.css   ← стили выбранной темы (если есть)
    /theme.css           ← цвета и CSS из админки
    /custom.css          ← файл администратора (если есть)
  </head>
  <body>
    partials/header.ejs  ← шапка, меню пользователя, баннеры, уведомления
    …содержимое шаблона страницы…
    partials/footer.ejs  ← подвал, app.js, скрипты страницы, custom.js
  </body>
</html>
```

## Экраны и шаблоны

| Экран | Адрес | Шаблон |
| --- | --- | --- |
| Главная | `/` | `views/home.ejs` |
| Пространства | `/spaces`, `/spaces/:key`, `/spaces/new` | `views/spaces/index.ejs`, `show.ejs`, `form.ejs` |
| Статья | `/pages/:id` | `views/pages/show.ejs` |
| Редактор | `/pages/:id/edit`, `…/pages/new` | `views/pages/form.ejs` |
| История, версия, сравнение | `/pages/:id/history`, `/versions/:v`, `/diff` | `views/pages/history.ejs`, `version.ejs`, `diff.ejs` |
| Поиск, метки | `/search`, `/labels` | `views/search.ejs`, `views/labels/*.ejs` |
| «Что создать?» | `/create` | `views/create.ejs` |
| Вход, регистрация | `/login`, `/register` | `views/auth/*.ejs` |
| Профиль | `/profile` | `views/profile.ejs` |
| Настройки | `/settings/*` | `views/settings/account.ejs`, `security.ejs`, `appearance.ejs` |
| Администрирование | `/admin/*` | `views/admin/index.ejs`, `settings.ejs`, `ldap.ejs`, `users.ejs`, `user.ejs` |
| Ошибка | любой | `views/error.ejs` |

## Три типа макета

1. **Пространство и статья** — сетка `.space-layout`: слева дерево страниц (`partials/space-sidebar.ejs`), в центре содержимое, справа оглавление «На этой странице» (появляется при двух и более заголовках).
2. **Настройки и администрирование** — оболочка `.settings-shell` в стиле «Системных настроек» macOS: слева меню разделов с цветными плитками (`partials/settings-nav.ejs`), справа карточки `.settings-card`.
3. **Одиночные страницы** (главная, поиск, профиль, вход) — центрированный контейнер.

## Адаптивность

| Ширина | Что меняется |
| --- | --- |
| ≤ 1200px | прячется колонка оглавления |
| ≤ 900px | дерево пространства выезжает по кнопке «☰ Страницы»; меню настроек становится горизонтальной лентой; редактор — в одну колонку |
| ≤ 640px | компактная шапка, поля форм в столбик, профиль по центру |

Есть и **печать**: навигация, кнопки и комментарии скрываются, остаётся текст статьи.

## Работа без JavaScript

Всё основное работает без скриптов:

- выпадающие меню и ветки дерева — нативный `<details>`;
- выбор темы — радиокнопки внутри карточек `<label>`;
- переключатели iOS — стилизованные чекбоксы (`input.switch`);
- подтверждение удаления вводом ключа или логина — обычные формы.

JavaScript добавляет предпросмотр, горячие клавиши, загрузку перетаскиванием, окна подтверждения, живую подсветку оглавления и мгновенное переключение режима. Подробнее: [Шаблоны EJS](page:Шаблоны EJS), [Стили и темы оформления](page:Стили и темы оформления), [Клиентский JavaScript](page:Клиентский JavaScript).
