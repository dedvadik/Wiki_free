Внешний вид и поведение сайта настраиваются на **трёх уровнях** — от простого к продвинутому.

[[toc]]

## 1. Админ-панель (без программирования)

**Администрирование** (доступно администраторам) — разделы «Общие», «Доступ и права», «Оформление», «LDAP», «Пользователи»:

- название сайта, подзаголовок, логотип, иконка вкладки, текст подвала;
- баннер-объявление под шапкой;
- приветствие на главной странице (Markdown);
- **тема оформления**: «Классическая» или «iCloud» (каждый пользователь может выбрать свою в «Настройки → Оформление»), светлый/тёмный режим по умолчанию;
- **доступ**: закрытая вики (только для вошедших), открытая/закрытая регистрация, роль новых пользователей, комментарии;
- **оформление**: готовые цветовые пресеты, основной цвет, цвета шапки, шрифт, размер текста, ширина колонки, ширина боковой панели, скругление углов, тема по умолчанию (светлая/тёмная/системная);
- **собственный CSS** — переопределяет любые стили.

Изменения применяются сразу, без перезапуска.

## 2. Переменные окружения (при развёртывании)

Файл `.env` рядом с `docker-compose.yml`. Основные переменные:

| Переменная | Назначение |
| --- | --- |
| `APP_PORT` | Порт на хосте (по умолчанию 8080) |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | Первый администратор |
| `SESSION_SECRET` | Секрет подписи cookie |
| `UPLOAD_MAX_MB` | Максимальный размер вложения |
| `VIDEO_MAX_MB` | Максимальный размер видео |
| `SETTING_<КЛЮЧ>` | Значение настройки по умолчанию, например `SETTING_SITE_NAME=Wiki` |

## 3. Папка `custom/` (полный контроль)

Папка `custom/` монтируется в контейнер и имеет **приоритет** над встроенными файлами:

```text
custom/
├── views/            ← шаблоны EJS: файл с тем же именем заменяет встроенный
│   └── partials/
│       └── footer.ejs
└── public/           ← статика, доступная по адресу /имя-файла
    ├── custom.css    ← подключается автоматически на всех страницах
    ├── custom.js     ← подключается автоматически на всех страницах
    ├── logo.png      ← можно указать как /logo.png в настройках логотипа
    └── themes/       ← свои темы оформления (theme.json + theme.css)
```

:::tip Пример
Чтобы полностью заменить подвал сайта, скопируйте `views/partials/footer.ejs` в `custom/views/partials/footer.ejs` и отредактируйте копию. После изменения файлов в `custom/` перезапустите контейнер: `docker compose restart app`.
:::
