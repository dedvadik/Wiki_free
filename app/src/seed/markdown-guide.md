Страницы пишутся в формате **Markdown** — простой текстовой разметке. Панель инструментов редактора вставляет нужные символы за вас, а справа сразу виден результат.

[[toc]]

## Текст

| Разметка | Результат |
| --- | --- |
| `**жирный**` | **жирный** |
| `_курсив_` | _курсив_ |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `` `код` `` | `код` |
| `[ссылка](https://example.com)` | [ссылка](https://example.com) |

## Заголовки

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

Заголовки автоматически попадают в оглавление справа («На этой странице») и получают якорь — наведите на заголовок и нажмите `#`, чтобы получить ссылку на раздел.

## Статусы

Вставляются так: `{{status:green:ГОТОВО}}`. Доступные цвета:
{{status:grey:grey}} {{status:red:red}} {{status:yellow:yellow}} {{status:green:green}} {{status:blue:blue}} {{status:purple:purple}}

## Картинки, видео и файлы

Нажмите кнопку 📎 в панели инструментов, **перетащите** файл в редактор или **вставьте** картинку из буфера (Ctrl+V). Файл загрузится, а в текст добавится ссылка:

```markdown
![описание картинки](/uploads/....png)
![запись экрана](/uploads/....mp4)
[документ.pdf](/uploads/....pdf)
```

Видео (mp4, webm, mov) пишется так же, как картинка, и **воспроизводится прямо в статье** — с перемоткой и полноэкранным режимом. Видео можно загрузить до 200 МБ, остальные файлы — до 20 МБ (лимиты меняет администратор сервера).
