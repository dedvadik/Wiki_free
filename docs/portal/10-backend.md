## Слои

```text
routes/      ← «что делать с запросом»: разобрать ввод, проверить права, выбрать шаблон
   │ вызывают
services/    ← «правила предметной области»: настройки, Markdown, дерево страниц, вход, LDAP
   │ используют
db/          ← «как хранить»: пул соединений, транзакции, миграции
utils/       ← мелкие общие помощники (HTTP, форматирование, иконки)
middleware/  ← то, что выполняется для каждого запроса (пользователь, CSRF, ошибки)
```

## Соглашения

### Ошибки — через HttpError

```javascript
import { HttpError, parseId } from '../utils/http.js';

pagesRouter.get('/pages/:id/history', async (req, res) => {
  const page = await loadPage(parseId(req.params.id)); // "abc" → 404
  if (!page) throw new HttpError(404, 'Страница не найдена');
  // ...
});
```

Express 5 сам передаёт исключения из async-обработчиков в `errorHandler`. Он показывает страницу ошибки с нужным кодом, а для `/api/*` отвечает JSON.

### Формы: POST → Redirect → GET

- **Успех** → `req.flash('success', '…')` и `res.redirect(…)`. Обновление страницы (F5) не отправит форму повторно, а уведомление переживёт редирект.
- **Ошибка валидации** → та же форма заново со статусом `422`, списком `errors` и **введёнными** значениями, чтобы пользователю не пришлось заполнять всё снова.
- **Конфликт версий** → `409`, см. [Статьи: разметка, дерево, версии, поиск](page:Статьи: разметка, дерево, версии, поиск).

### Валидация

Функции проверки возвращают **массив текстов ошибок**, а не бросают исключения: так пользователь видит все проблемы формы сразу. Примеры: `validateUserInput`, `readPageForm`, `readSpaceForm`, `updateSettings`. Ошибки, которые можно показать пользователю как есть, бросаются как `ValidationError`, например «логин уже занят».

### Параллельные запросы

Независимые запросы к БД выполняются через `Promise.all`. Так страница статьи загружает пространство, дерево, предков, дочерние страницы, метки, комментарии, вложения и избранное одновременно.

### Права

Проверяются на сервере в каждом маршруте: `requireLogin`, `requireRole('editor')`, `requireRole('admin')`. Скрытые кнопки в шаблоне — только удобство, а не защита.

## Помощники из utils/

| Функция | Что делает |
| --- | --- |
| `parseId(value)` | строгий разбор числового id из URL; всё остальное → 404 |
| `safeReturnTo(url)` | разрешает только локальные пути `/…` (не `//evil.com`) |
| `backUrl(req, fallback)` | адрес из `Referer`, если он с нашего сайта |
| `regenerateSession(req)` | промис-обёртка над `req.session.regenerate` |
| `formatDate`, `formatDateTime`, `timeAgo` | даты по-русски (`Intl`), часовой пояс из `TZ` |
| `fileSize(bytes)` | «1,5 МБ» |
| `plural(n, one, few, many)` | «1 страница / 3 страницы / 11 страниц» |
| `authorName(name)` | имя автора или «удалённый пользователь» |
| `avatarHue(name)` | стабильный оттенок цвета аватара из имени |
| `icon(name, class)` | SVG-иконка (`<%- icon('user') %>`) |

Все помощники доступны в шаблонах через `res.locals`, см. [Middleware](page:Middleware).
