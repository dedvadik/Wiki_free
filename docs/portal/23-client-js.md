JavaScript в браузере только улучшает интерфейс: сайт работает и без него. Все скрипты — отдельные файлы в `public/js/`, встроенных `<script>` нет, этого требует политика безопасности CSP.

[[toc]]

## Файлы

| Файл | Где подключается | Назначение |
| --- | --- | --- |
| `theme-init.js` | в `<head>`, **синхронно** | выставляет светлый/тёмный режим до первой отрисовки |
| `app.js` | на всех страницах (`defer`) | общие улучшения интерфейса |
| `editor.js` | в редакторе страниц | Markdown-редактор |
| `admin.js` | в разделах настроек сайта | поля цвета, пресеты, живой предпросмотр |

Скрипты находят элементы по **data-атрибутам** (`data-action`, `data-md`, `data-pref`, `data-editor-*`), а не по классам. Поэтому шаблон можно менять, не трогая JavaScript.

## theme-init.js

Написан на ES5 для максимальной совместимости. Читает `localStorage['color-mode']`, при его отсутствии — `data-default-mode` с `<html>`; значение `auto` разрешает через `matchMedia('(prefers-color-scheme: dark)')`. Итог записывается в атрибут `data-mode`.

## app.js

| № | Возможность | Как включается в разметке |
| --- | --- | --- |
| 1 | переключатель светлого/тёмного режима (кнопка ◐) | `data-action="toggle-theme"` |
| 2 | окно подтверждения перед отправкой формы | `<form data-confirm="Текст?">` |
| 3 | закрытие выпадающих меню кликом мимо и клавишей Esc | `<details class="dropdown">` |
| 4 | выезжающая боковая панель на телефоне | `data-action="toggle-sidebar"` |
| 5 | кнопка «Копировать» у блоков кода | автоматически в `.page-content pre` (только HTTPS или localhost) |
| 6 | подсветка текущего раздела в оглавлении при прокрутке | `IntersectionObserver` по заголовкам |
| 7 | печать | `data-action="print"` |
| 8 | настройки браузера на «Настройки → Оформление» | `<input data-pref="color-mode">`, `data-pref="editor-mode"` |

Настройки браузера применяются **сразу** без кнопки «Сохранить»: значение пишется в `localStorage`, а режим сразу меняется в атрибуте `data-mode`.

## editor.js — Markdown-редактор

```text
┌ панель инструментов (data-md="bold" …) ─────────── Текст | Оба | Просмотр ┐
│ textarea (data-editor-input)       │ предпросмотр (data-editor-preview)   │
└────────────────────────────────────┴──────────────────────────────────────┘
```

| Возможность | Как сделано |
| --- | --- |
| Кнопки разметки | объект `ACTIONS`: `wrap` (обернуть выделение), `prefixLines` (префикс строкам), `insertBlock` (вставить блок); `textarea.setRangeText` сохраняет выделение |
| Горячие клавиши | Ctrl/⌘ + B, I, K; Tab — отступ; Ctrl+S — сохранить с любого места страницы (`form.requestSubmit()`) |
| Живой предпросмотр | `POST /api/preview` через 400 мс после последнего нажатия (debounce); предыдущий запрос отменяется `AbortController`; HTML приходит уже очищенным с сервера |
| Режимы вида | `data-mode` у `.editor-workspace`; выбор помнится в `localStorage['editor-mode']` |
| Загрузка файлов | 📎, вставка из буфера (Ctrl+V), перетаскивание; заглушка «Загрузка…» заменяется ссылкой из ответа; id файла добавляется в скрытое поле `attachment_ids` |
| Защита от потери текста | `beforeunload` спрашивает «Покинуть страницу?», если есть несохранённые изменения |

Чтобы добавить кнопку, нужны `<button data-md="имя">` в `views/pages/form.ejs` и функция `имя` в `ACTIONS`.

## admin.js

- **Поля «цвет поверх темы»** состоят из палитры (без `name`) и текстового поля `#RRGGBB` (оно и отправляется). Скрипт синхронизирует их в обе стороны; кнопка «как в теме» очищает поле.
- **Цветовые пресеты** — кнопки с `data-preset='{"primary_color":"#…"}'`: заполняют поля, пустые значения очищают.
- **Живой предпросмотр**: пока настройки не сохранены, скрипт меняет CSS-переменные текущей страницы (`--primary`, `--header-bg`, `--header-text`); очищенное поле возвращает цвет темы.
