[[toc]]

## Первый администратор (services/bootstrap.js)

`ensureInitialAdmin()` срабатывает, только если в базе **нет ни одного пользователя** и задан `ADMIN_PASSWORD`. Логин, email и имя берутся из `ADMIN_USERNAME`, `ADMIN_EMAIL`, `ADMIN_DISPLAY_NAME`. Пароль проверяется теми же правилами, что и при регистрации. Слишком короткий пароль даёт предупреждение в журнале, и администратор **не создаётся**.

Если `ADMIN_PASSWORD` не задан, администратором становится **первый зарегистрировавшийся**: регистрация всегда открыта, пока пользователей нет.

## Демо-контент

`seedDemoContent()` при `SEED_DEMO=true` на базе без пространств создаёт одной транзакцией пространство **DOCS** («Документация») и три страницы. Их тексты лежат в `src/seed/*.md`:

| Страница | Файл |
| --- | --- |
| Добро пожаловать | `welcome.md` |
| └ Руководство по разметке | `markdown-guide.md` |
| └ Кастомизация сайта | `customization.md` |

Автор демо-страниц — первый администратор. У каждой страницы есть версия 1 в истории.

## Секрет сессий

Если `SESSION_SECRET` пуст, `server.js` генерирует секрет (48 случайных байт) и сохраняет его в `DATA_DIR/.session-secret` с правами `0600`. Подробнее — [Запуск и обработка запроса](page:Запуск и обработка запроса).

## Импорт этой документации (tools/import-docs.js)

Страницы пространства **CODE** («Код портала») не пишутся вручную: они публикуются из репозитория.

```text
docs/portal/
├── manifest.json        ← пространство и дерево страниц
├── 00-overview.md       ← текст страницы «Как устроен портал»
├── 01-startup.md
└── …
```

Запуск:

```bash
npm run docs:import                              # локально
docker compose exec app npm run docs:import      # в Docker
```

Как работает импорт:

1. Читает `manifest.json` и все Markdown-файлы **до** записи в базу, поэтому опечатка в имени файла ничего не испортит.
2. Одной транзакцией создаёт или обновляет пространство (ключ, название, описание, иконка, цвет).
3. **Проход 1:** находит каждую страницу по заголовку в пространстве или создаёт пустую; выставляет родителя и порядок. После этого известны id всех страниц.
4. **Проход 2:** заменяет ссылки `[текст](page:Заголовок)` на `/pages/<id>` и записывает текст:
   - новая страница → версия 1 «Создано импортом документации»;
   - текст изменился → **новая версия** «Обновлено импортом документации»;
   - текст не изменился → страница не трогается, история не засоряется.
5. Обновляет метки из манифеста.

:::warning Правьте документацию в репозитории
Если отредактировать страницу прямо на портале, следующий импорт создаст новую версию с текстом из файла. Ручная правка останется в истории, её можно сравнить и восстановить, но актуальным станет текст из репозитория. Если переименовать страницу на портале, импорт создаст её заново под старым названием.
:::

Как добавить страницу — на странице [Как расширять портал](page:Как расширять портал).
